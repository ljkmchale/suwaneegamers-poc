# NPC Source Grounding Standards

## Purpose

Use this standard whenever creating or updating NPC pages. The goal is to make the brain useful without inventing certainty.

## Fact Categories

### Directly Documented

Use for things explicitly stated in source notes or session pages: names, titles, visible actions, direct quotes, locations, items, faction membership, combat behavior, and confirmed relationships.

### Strong Inference

Use for conclusions strongly supported by several documented facts, but not directly stated. Phrase these with care: "appears to," "likely," "suggests," or "reads as."

### Unconfirmed Or Open

Use for theories, unknown motives, unresolved names, unclear faction rank, and suspected relationships. Do not write these as settled facts.

## Required NPC Page Shape

- Scope: campaign-only boundary.
- Directly Documented Facts: session-grounded facts.
- Strong Inferences: useful reads, clearly marked.
- Relationships: only documented or marked as inferred.
- Open Questions: unresolved items.
- Source Anchors: exact session/source pages.

## Accuracy Rules

- Do not merge NPCs across campaigns unless the source explicitly says they are the same person.
- Preserve source spelling variants only as aliases or notes; pick one canonical spelling for the page.
- Do not upgrade a motive into fact. If the source only shows behavior, say what they did, then mark motive as inference.
- Do not make an NPC more important than the notes support. Importance can be marked as "potential" or "recurring."
- Prefer "the notes show" over "is" when describing uncertain agendas.
