# Item Source Grounding Standards

## Purpose

Use this standard for magic items, quest objects, letters, clues, and artifacts. Items often become theory engines, so every page should distinguish source facts from meaning.

## Required Item Page Shape

- Scope: campaign-only boundary.
- Directly Documented Facts: what the notes actually say happened.
- Strong Inferences: likely importance or function, clearly marked.
- Unconfirmed Or Open: unresolved meaning, origin, holder, or effect.
- Source Anchors: exact session/source pages.

## Accuracy Rules

- Do not state an item's purpose as fact unless the source says it.
- Do not assume a magical effect from symbolism.
- Track current holder only when documented.
- If an item changes, record the session and the observed change, not just a conclusion.
