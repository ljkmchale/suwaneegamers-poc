If using the Activate Sigil cantrip, there is a chance that it may not function correctly, so you should use the following formula to determine the chance of success.

Chance of Success = Familiarity (50%) + Level Bonus (3% x Level)

  - Familiarity: 50% chance of success if the caster has been to the location before.
  - Level Bonus: chance of success is increased by 3% for each level of the caster.
