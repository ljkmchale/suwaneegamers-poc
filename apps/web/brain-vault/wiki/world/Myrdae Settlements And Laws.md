## Laws (Ordinances)

### **Punishments**

Punishment for a crime can include one or more of the following, based on the nature of the crime, who or what the crime is committed against, and the criminal record of the convicted:

|  |  |
| :-: | :-: |
| Punishment | Description |
| Damages | payable to the injured party or victim’s kininability to pay damages leads to imprisonment and/or hard labor |
| Death |   |
| Edict | forbidding the convicted from doing somethingviolation of an edict can result in imprisonment, hard labor and/or a fine |
| Exile | for a number of years or harmons |
| Fine | payable to the cityinability to pay the fine leads to imprisonment and/or hard labor |
| Flogging | a set number of strokes |
| Hard Labor | for a period of days, stretches, harmons or years, depending on the seriousness of the crime |
| Imprisonment | placed in jail or dungeon for a period of days, stretches or harmons, depending on the seriousness of the crime |

### **Crimes against Lords, Officials and Nobles**

|  |  |
| :-: | :-: |
| Crime | Punishment |
| Assaulting or impersonating a Lord | death |
| Assaulting or impersonating an official or noble | flogging, imprisonment up to a stretch and fine up to 500 gp |
| Blackmailing an official | flogging and exile up to 10 years |
| Bribery or attempted bribery of an official | exile up to 20 years and a find up to double the bribe amount |
| Murder of a Lord, official, or noble | death |
| Using magic to influence a Lord without consent | imprisonment up to a year and fine or damages up to 1,000 gp |

### **Crimes against the City**

|  |  |
| :-: | :-: |
| Crime | Punishment |
| Arson | death or hard labor up to 1 year, with fines and/or damages covering the cost of repairs plus 2,000 gp |
| Brandishing weapons without due cause | imprisonment up to a stretch and/or fine up to 10 gp |
| Espionage | death or permanent exile |
| Fencing stolen goods | fine equal to the value of the stolen goods and edict |
| Forgery of an official document | flogging and exile for 10 years |
| Hampering justices | fine up to 200 gp and hard labor up to a stretch |
| Littering | fine up to 2 gp and edict |
| Poisoning a city well | death |
| Theft | flogging followed by imprisonment up to a stretch, hard labor up to 1 year, or fine equal to the value of the stolen goods |
| Vandalism | imprisonment up to a stretch plus fine and/or damages covering the cost of repairs plus up to 100 gp |
| Using magic to influence an official without consent | fine or damages up to 1,000 gp and edict |

### **Crimes against Citizens**

|  |  |
| :-: | :-: |
| Crime | Punishment |
