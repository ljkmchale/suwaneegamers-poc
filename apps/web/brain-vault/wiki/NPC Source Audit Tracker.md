## Next NPC Expansion Standard

When fleshing out any new NPC, add:

- Directly Documented Facts
- Strong Inferences
- Unconfirmed Or Open
- Session-specific Source Anchors

Then only expand personality, motives, threat profile, or usefulness when the documentation supports it.
