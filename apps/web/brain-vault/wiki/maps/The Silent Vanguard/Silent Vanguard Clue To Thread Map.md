# Silent Vanguard Clue To Thread Map

## Trafficking / Warehouse Thread

- Warehouse letter -> crates, chains, cages, people, guards, 20-night shipment window.
- South warehouse near old stone ramp -> staging location.
- Gultren the Canvas Master / Sticky Pear Inn -> receiving contact.
- Colosseum network -> probable endpoint for trafficking.

## Corruption Thread

- Gilded Ledger -> financial or record-keeping arm of Tratta corruption.
- Salt and Cinder Press -> communications or broadsheet arm.
- Broadsheets from Brinecross -> colosseum corruption referenced.
- Both structures suggest an organized, multi-part operation in Tratta.

## The Long Night Thread

- Harold's key phrase -> The Long Night as drug operation name or location.
- Warehouse letter + shipment timing -> possible connection to Long Night operation.
- Warehouse, Gilded Ledger, Long Night may all be parts of the same network.

## Brinecross / Zombie Outbreak Thread

- Zombie fish / strange water / vegetable clues -> source of outbreak unclear.
- Linda / Nora -> herb/vegetable treatment clues; both left behind.
- Harold sick in stable -> possible low-level infection or poisoning.
- Deliberate origin (tied to trafficking?) vs. natural contamination: unresolved.

## Intelligence Thread

- Ivory/statue object from Harold's backpack -> unknown value or function; likely "the object of value" from Thorne's briefing.
- Warehouse letter -> current best evidence in party possession; Gultren the Canvas Master is the named recipient.
- The Long Night, warehouse, and Gilded Ledger may all be arms of the same network.
