# Bundled theme fonts

These WOFF2 files and font-face rules are the exact Google Fonts assets from the verified production bundle active on November 6, 2026. All eight families retain their weights, styles, Unicode subsets, fallback metrics and CSS variable names. Webpack emits the relative CSS assets into the immutable build; neither building nor viewing requires a Google Fonts request.

Each family is distributed under its accompanying OFL license, obtained from https://github.com/google/fonts/tree/main/ofl.
