# A New Adventure Living Chronicle

`a-new-adventure-chronicle.md` is refreshed from the campaign's canonical
player-notes Google Doc by `scripts/sync-chronicle.mjs`.

Run `node scripts/sync-chronicle.mjs a-new-adventure` from the repository root
to refresh the source, rebuild `a-new-adventure-chronicle.html`, and publish the
served copy to `content/chronicles/a-new-adventure.html`.

Approved session artwork belongs under
`apps/web/media/images/chronicles/a-new-adventure/` and is mapped by chapter in
`session-images.json` using `/media/images/...` URLs.
