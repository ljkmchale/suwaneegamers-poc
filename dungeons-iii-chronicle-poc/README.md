# Dungeons III Living Chronicle

`dungeons-iii-chronicle.md` is refreshed from the campaign's canonical
player-notes Google Doc by `scripts/sync-chronicle.mjs`.

Run `node scripts/sync-chronicle.mjs dungeons-iii` from the repository root to
refresh the source, rebuild `dungeons-iii-chronicle.html`, and publish the
served copy to `content/chronicles/dungeons-iii.html`.

Approved session artwork belongs under
`apps/web/media/images/chronicles/dungeons-iii/` and is mapped by chapter in
`session-images.json` using `/media/images/...` URLs.
